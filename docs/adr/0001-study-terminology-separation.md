# 0001 — 학습 용어 체계 분리

> **개정 (2026-08)**: 본 ADR의 "학습 세션/학습 스케줄/학습 이력" 용어 분리 결정은 **채택되지 않았습니다.** 실제 코드베이스는 기존 "복습(Review)" 계열 용어(`ReviewCard`, `ReviewRepository`, `review_cards`·`review_logs` 테이블, 복습 탭/화면)를 그대로 사용합니다. `StudyLog` 클래스명만 채택되었습니다. 이 ADR은 현 상태를 기록으로 보존하되, 유효한 규범은 CONTEXT.md(Ubiquitous Language — 복습/복습 카드/복습 로그)를 따른다.

기존 "복습(Review)"이라는 포괄적 용어를 세 가지 고유 용어로 분리하기로 결정했습니다. "학습 세션(StudySession)", "학습 스케줄(StudySchedule)", "학습 이력(StudyLog)"은 각각 다른 도메인 개념을 나타내며, 혼동을 방지하기 위함입니다.

이 결정은 코드베이스 전체의 네이밍 컨벤션에 영향을 미치며, 이후 변경 비용이 높으므로 기록합니다.
