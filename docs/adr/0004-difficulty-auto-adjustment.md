# 0004 — 복습 결과 난이도 자동 반영

## 배경

MASTERED(난이도 ≤ 2 단어 수)는 대시보드 LEDGER SUMMARY·설정 통계·마스터 정원 수료증의 핵심 지표지만, 기존에는 사용자가 단어 폼의 별점으로 설정한 값에만 의존했습니다. 아무리 복습을 잘해도 사용자가 별점을 낮추지 않는 한 MASTERED는 늘지 않아, "학습 성과가 숙달로 이어지지 않는" 단절이 있었습니다.

## 결정

복습 결과를 단어 난이도(difficulty 1~5)에 자동 반영합니다.

- **정책**: 정답이면 1 하락, 오답이면 1 상승. 1~5 범위를 유지(클램프)합니다.
- **진입점**: 모든 학습 도구(퀴즈 4종·플래시카드·매칭 2종)가 거치는 `ReviewRepository.processReviewResult`에 적용해 일관된 동작을 보장합니다.
- **설정 토글**: `auto_difficulty` 설정 키(기본 켬)로 끌 수 있습니다. 값이 `'false'`면 비활성화되고, 설정이 없거나 다른 값이면 활성화됩니다. 별도 DB 마이그레이션 없이 settings 테이블을 사용합니다.
- **부수 효과 격리**: 난이도 갱신은 복습 카드 갱신 이후의 2차 부수 효과로 취급하며, 실패해도 복습 기록 경로(카드 갱신·다이얼로그·업적 평가)를 막지 않도록 격리합니다. 리뷰카드 존재 여부와도 독립적으로 처리합니다.

## 영향

- MASTERED가 복습 성과를 반영하는 **동적 지표**가 되며, 이를 활용해 마스터드 업적(Mastered 50/200/500)을 신설했습니다.
- 마스터 정원 **레벨·배지는 단어 수 기준을 유지**합니다. 난이도는 양방향으로 변동하므로 레벨 계산에 반영하면 "단어를 틀렸더니 정원이 시든다"는 회귀 UX가 생기기 때문입니다.
- 토글을 끄면 난이도는 사용자 별점 기반으로 고정되어, 기존 사용자(설정 미저장)는 기본 켬 동작을 그대로 경험합니다.
- 관련 결정: 매칭 완료도 퀴즈와 동일하게 `logReview` + `processReviewResult`(SM-2 일정)를 호출하도록 확장했습니다.
