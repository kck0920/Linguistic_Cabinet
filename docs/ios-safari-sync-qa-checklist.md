# iOS Safari 구글 동기화 세션 검증 체크리스트

웹에서 한 번 로그인하면 **'연결 해제' 전까지 세션이 유지**된다는 보장을
실제 iOS Safari에서 검증하기 위한 수동 테스트 문서.

> 코드 근거: `google_session_storage_web.dart`(이중 저장),
> `google_auth_service.dart:578`(갱신 실패 시에도 세션 보존),
> `google_token_refresh_web.dart`(Serverless 갱신 — ITP 회피 설계)

## 0. 사전 조건 (중요)

- [ ] **반드시 배포된(Vercel) URL에서 테스트** — `/api/google/connect|token|disconnect`
      서버리스 함수가 필요하다. 로컬 `python3 -m http.server` 정적 서버에는
      백엔드가 없어 토큰 교환 단계에서 실패한다.
- [ ] Vercel 환경변수 확인: OAuth client secret, refresh token 암호화 키가 설정되어 있는지
- [ ] 테스트 기기 정보 기록:
      - 기기 모델: ____________
      - iOS 버전: ____________ (설정 > 일반 > 정보)
      - Safari 팝업 차단: ON / OFF (설정 > 앱 > Safari > 팝업 창 차단)
      - "웹사이트 추적 방지" 설정: ____________
- [ ] 디버깅 준비: Mac Safari > 개발자용 메뉴 > 기기 연결 → **Safari 웹 인스펙터**
      (또는 iPhone에서 설정 > 앱 > Safari > 고급 > 웹 인스펙터 ON)

### 콘솔에서 볼 로그 태그

| 태그 | 의미 |
|------|------|
| `Web token successfully refreshed via Serverless API` | 1차 갱신 성공 (ITP 무관) |
| `via GIS Silent Token Client` | 2차 갱신 성공 |
| `GIS silent token refresh error` | 2차 실패 (Safari에선 예상됨 — 문제 아님) |
| `preserving user session` | 갱신 실패했지만 세션 보존됨 |
| `restored from SQLite backup` | localStorage 소실 → SQLite에서 복원됨 |
